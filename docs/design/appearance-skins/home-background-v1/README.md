日期：2026-10-21。用户最新参考明确采用“右侧大幅人物、左侧少量主题文字”的构图。这里将人物作为主页的主要视觉，并延续启动样片的浅蓝场景；替代本轮最初把大幅人物仅作为浅水印的尝试。产品布局仍沿用当前 Hemi，不重新设计侧栏、字体体系、输入框或任务卡。

打开 [预览页](index.html) 可切换主页和会话阅读两张静态效果图。
