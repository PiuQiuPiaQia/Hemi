# 晴海蓝启动动效预演 v1

日期：2026-10-21。打开 [index.html](index.html) 可播放、暂停、拖动进度、重播或跳过。无网络请求、无需安装或登录。[MP4 样片](hemi-blue-startup-preview-v1.mp4) 为同一时间轴的 1440×960、30fps、6 秒无声导出。

这是供评审的运镜与交接预演，未接入 Hemi 生产启动流程。当前人物是一张透明立绘，经位移、缩放和旋转入场；不包含眨眼、挥手、口型或衣发骨骼动画。界面来自 Hemi fixture 截图，是静态纹理，不能操作。截图中的示例会话及验证文字不代表本次功能已实现或测试通过。

| 时间 | 画面 |
| --- | --- |
| 0–1.15s | 晴海蓝场景与人物入场，展示皮肤名称 |
| 1.15–3.25s | Hemi 界面以倾斜平面浮现，人物位于前景 |
| 3.25–5s | 界面放大、透视归零，前景人物淡出 |
| 5–6s | 保持现有 Hemi 布局，侧栏人物背景落定，验证长列表下的最终状态 |

页面普通模式自动播放一次；系统开启减少动态效果时直接展示结束画面，可手动重播。空格播放 / 暂停，Esc 跳过；切换至隐藏标签页时暂停。`?capture` 模式隐藏外围控制，可用 `window.preview.seek(ms)` 确定性取帧。

素材引用现有 [蓝色母版](../v1/masters/cafe-blue.png)、[Hemi 标记](../v1/classic.svg) 和 [已确认的界面截图](../../../requirements/assets/appearance-and-skins/sidebar-full-list.png)，源图未改动。场景色块、光环、透视及过渡由 HTML/CSS/JavaScript 绘制。这里沿用已有侧栏背景确认图作为交接落点；新增全窗口场景背景、正式人物动画和真实 DOM 交接的评审由[扩展技术方案](../../../technical/appearance-startup-and-background.md)继续覆盖。
