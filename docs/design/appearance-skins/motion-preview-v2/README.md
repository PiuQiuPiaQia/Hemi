# 冷启动与主页两段动效预演 v2

日期：2026-10-21。用户已明确两种动画都需要。首支以晴海蓝打样，保留已确认的右侧人物、左侧 `Smile / DeepSeek` 题字和当前 Hemi 布局。

打开 [交互预演](index.html)，可重播冷启动、切换主页轻动效、查看静态会话阅读、暂停、拖动或跳过。冷启动结束后自动进入主页轻动效；预览控制条仅用于评审，不是新增产品设置。另附 [15 秒无声样片](hemi-blue-startup-and-idle-v2.mp4)：前 6 秒冷启动，后 9 秒主页轻动效。

## 1 本次实际交付

| 段落 | 已做效果 | 当前素材边界 |
| --- | --- | --- |
| 冷启动 0–1.4s | 右侧人物入场、题字由蒙版逐步揭示、细弧线描边写入 | 人物为透明 PNG 运镜，字形本身没有逐笔路径动画 |
| 冷启动 1.4–5.1s | 只读界面平面浮现、透视展开，前景人物退场 | 界面为从实际 fixture 导出的 DOM/CSS 快照，不是真实运行中的应用 |
| 冷启动 5.1–6s | 完成视觉交接，保留已确认的主页 | 交接帧与主页轻动效起始帧逐像素一致 |
| 主页常驻 | 人物整图轻浮动（9s 周期，位移约 ±2.2px）与缓慢光效（14s 周期） | 尚不含眨眼、转头、挥手、发丝或衣饰关节动画 |
| 会话阅读 | 收起装饰文案、提高阅读区遮盖、停止常驻动效 | 通过预览按钮切换至独立只读快照，未绑定真实会话状态 |

减少动态效果时默认进入静态主页；页面隐藏时暂停。预演所有运动由统一时钟控制，已冻结快照原有 CSS 动画和过渡，支持确定性取帧。快照控件设为 inert，既不操作真实会话，也不调用模型或服务。人物和头像继续引用已有母版，无程序修图。

## 2 完整人物动画还需制作

- 冷启动前景：与当前人物身份一致的眼神变化、转头和一次引导手势；提供透明前景/遮挡层及静态交接姿态。
- 主页常驻：单独制作平缓的头发、衣饰和躯干动画，以及可低频触发的眨眼；循环接缝须平顺，避免循环挥手等持续吸引注意的动作。
- 共享结束状态：启动演出的结束姿态、主页循环的起始姿态、静态回退图要连续。

当前工具环境未连接可用的视频生成服务，未提交外部或付费生成。当前预演不代表上述人物动作已完成，也不代表动画已经接入生产应用。分层素材准备与制作接入见[扩展技术方案](../../../technical/appearance-startup-and-background.md)。

## 3 文件与检查

- index.html：预览控制器，通过本地 iframe 消息切换场景与统一时钟。
- scene-welcome.html / scene-conversation.html：从当前 renderer fixture 导出的只读 DOM/CSS，引用原人物素材；不含应用运行脚本。
- scene-motion.js / scene-motion.css：本轮 authored 动效与状态切换。
- [qa.json](qa.json)：基线 commit、环境、命令、视觉交接一致性、跳过、模式切换、减少动态效果与窄宽检查。

本次未修改产品代码。真实启动就绪、焦点、IPC、多窗口、Vite 与构建 renderer 接入、Electron 平台解码及常驻性能预算仍需实现和验收。快照会话中的“测试通过”等正文是演示内容，不是本次功能的验证证据。
