# Hemi Bot 视觉交互稿

本目录保留首轮方案。包含顶部手动同步模型、多会话和云端目录选择的最新稿见 [v2](../v2/README.md)。本页评审结论仅适用于本目录的历史版本。

日期：2026-10-22。配套需求：[Hemi 云端 Bot 功能需求文档](../../../requirements/cloud-bot.md)。Claude Code 两轮 review 已通过，详见[评审记录](REVIEW.md)。

本稿展示一个 Bot 连接一台 Linux 云服务器的完整体验：首次打开左侧 Bot Tab 后创建连接，确认服务器身份，配置模型和工作目录，初始化云端服务，随后直接进入 Bot 对话。首次设置结束后不再显示引导，不增加 Bot 或主机列表。

这是独立的可点击设计原型，全部服务器、模型、指纹与任务记录均为演示数据。页面不执行 SSH、不读取真实凭据、不调用模型、不安装云端组件。密码与 API Key 输入框无需填写真实内容。

## 查看与操作

在浏览器打开 [index.html](index.html)，从“创建连接”开始体验。顶部设计工具栏可以切换状态，也可以点击“从头体验”。工具栏用于评审，不进入产品。

原型可以完成连接、指纹确认、初始化、发送任务、查看执行过程、授权、文件预览和示例下载、设置、断开及重连、停止或启动 Bot、移除连接。界面中的技能、工作流与全局设置仅保留现有导航位置，未在本稿重复实现。

真实点击主线中，初始化和任务执行会以短延迟模拟完成。顶部菜单选中的“正在初始化”“执行中”等状态保持静止，便于评审。连接地址中输入 `fail` 可体验模拟的认证失败。

## 视觉基准

本稿使用 Hemi 经典皮肤的中性灰和系统字体：白色内容区、`--bg-rail` 浅灰外壳、墨色主按钮、绿色连接与完成状态。关键颜色快照为 `--ink #1a1a19`、`--muted #696966`、`--bg-rail #f6f6f5`、`--bg-canvas #ffffff`、`--accent #566e5d`。新样式只引用这些 token，不引入独立的配色体系。

沿用 48px 图标栏、52px 顶栏、13px 控件、15px 对话正文、6/10/14/20px 圆角等级。连接和配置采用 464px 单列，日常对话采用 720px 阅读列；保持与现有页面接近的信息密度。设置是右侧面板，主机指纹和维护动作使用轻量确认弹窗。

设计中最醒目的元素是当前步骤或当前任务。每屏只保留一个主要操作；不加入营销图、大型装饰、统计卡片或多层面板。进度使用真实阶段的表达方式，不设计虚构的百分比。当前经典皮肤不提供独立深色版本。

## 关键交互约定

- 切换到普通对话不会停止云端任务，也不会在后台完成时强行切回 Bot。
- 连接中断不展示“Bot 已停止”。离线时保留草稿，但不接受新指令或把 Enter 当成发送。
- 新授权等待用户处理。拒绝推送后明确显示“未执行推送”，不会把摘要生成成功混同为推送成功。
- 停止当前任务仍保留 Bot 服务；停止 Bot 则关闭常驻与自动启动。两者分别表达并展示结果。
- 初始化取消与初始化失败分别表达。已完成的步骤保留，下次检测后继续。
- 配置弹窗取消不保存；弹窗使用焦点限制、背景 inert、Esc 关闭和入口焦点恢复。
- 移除连接明确不删除云端文件或模型密钥。可选择先停止，再移除本机绑定。
- 窄窗口保留 48px 导航，表单和面板内部滚动；不通过隐藏关键操作解决高度不足。
