# Hemi Bot 视觉交互稿评审记录

日期：2026-10-22（Asia/Shanghai）。评审对象为本目录的独立设计原型，需求依据为 [cloud-bot.md](../../../requirements/cloud-bot.md)。

Claude Code 已完成两轮只读 review。第一轮实际查看了 9 张桌面、375px 窄窗口和 1180×720 画面，并检查需求、交互代码和验证记录；第二轮查看修改后的代码、检查脚本及 4 张针对性截图。最终结论为 **PASS，无阻断问题**。

视觉方向保留 Hemi 的导航、字体、浅色皮肤、墨色主按钮和低饱和状态色。review 未要求更换布局风格，修改集中在交互状态与焦点行为。

## 问题与修改

| 级别 | 第一轮问题 | 最终处理 |
| --- | --- | --- |
| P1 | 离线状态下仍能批准授权，随后误显示推送成功 | 离线授权卡只读，按钮与处理函数同时拦截；重连后仍恢复到待确认 |
| P1 | 重连固定进入已完成，丢掉待命、执行、授权或停止状态 | 分开维护模拟云端状态和离线快照，按核对结果恢复；受理未知只核对原指令，不新增消息 |
| P2 | 连接中切走再回来，连接计时被清理且表单一直禁用 | 返回到保留地址、可以继续的连接表单，不保留失去出口的连接中状态 |
| P2 | 启动 Bot 后清空已有对话与交付文件 | 保留历史，根据停止前状态恢复到结果页或任务已停止页 |
| P3 | 取消配置未回滚模型模式，切换选项丢掉目录草稿 | 模型模式、接口和目录统一使用编辑草稿，保存后才提交；取消完整丢弃 |
| P3 | 嵌套弹窗和动态重绘后焦点丢失或落入背景 | 为入口提供唯一 ID，排除 inert 背景；逐层返回并恢复入口或原控件焦点 |

第二轮已逐项确认以上六项问题关闭。另有三项非阻断意见也在交付时处理：

- 窄窗口的一张图在改视口后立即截取，出现合成帧瑕疵；改为等待浏览器完成两帧布局与绘制后重新导出。
- 已安装后返回配置重新初始化，改为明确显示“检查已有运行组件”和“直接复用”，不暗示重复安装。
- 验证记录把 Git 提交改为代码基线，并明确本稿是未提交工作区文件；另记录每个被测源文件的 SHA-256，避免把基线提交当成设计成品版本。

## 验证与证据

[validation.json](exports/validation.json) 记录最终环境、代码基线、被测原型文件哈希、20 项检查和 40 张截图。检查由原型作者运行，Claude Code 复核了记录，没有替作者执行测试。

交互检查覆盖完整首次流程、指纹勾选、初始化重试、跨 Tab 后台完成、离线草稿、禁止离线发送、授权允许或拒绝、嵌套弹窗及焦点、启动后保留历史、移除绑定、示例文件下载，以及针对六项 review 问题的回归操作。

画面覆盖 1440×900、768×1024、375×812 和 1180×720。导航宽度、顶栏高度、弹窗边界、页面横向溢出、脚本错误及减少动态效果均通过检查。Hemi 当前经典皮肤没有独立深色稿，本次没有扩展主题。

重点复核画面：[离线授权桌面](exports/offline-approval-1440.png)、[离线授权窄窗口](exports/offline-approval-375.png)、[初始化已取消](exports/init-canceled-1440.png)、[窄窗口设置](exports/settings-375.png)。

以上结论只针对视觉和模拟交互，不证明真实 SSH、云端服务、模型、驻留或权限执行已经实现。后续功能开发仍需按需求文档进行真实主机验收。
