# Hemi Bot 视觉交互稿 v2

> 本版保留为历史参考。当前共用普通对话组件的交互稿见 [v3](../v3/README.md)。

当前功能基线已更新为[需求 1.2](../../../requirements/cloud-bot.md)及[普通对话复用约定](../conversation-reuse.md)：正式实现共用普通对话的非语音功能。本目录保留云端差异的独立交互参考，简化演示不代表完整产品功能范围。

日期：2026-10-22。原稿依据需求 1.1 绘制，当前范围见上方需求 1.2。本稿增加顶部手动同步本机模型、单 Bot 多会话，以及每会话的模型和云端运行目录选择。Claude Code 已完成评审和收尾复核，最终 PASS，详见[评审记录](REVIEW.md)。

这是可点击的独立设计原型。所有服务器、模型、目录、指纹和任务都是演示数据；不读取本机模型配置或真实凭据，不执行 SSH、模型调用和云端安装。界面中的同步与执行结果为模拟反馈。

## 查看与操作

打开 [index.html](index.html)，从首次引导体验完整流程。顶部评审工具栏可切换“多会话对话”“顶部手动同步模型”“浏览云端文件夹”等画面，工具栏不进入正式产品。上一轮稿保留在 [v1](../v1/README.md)。

日常使用保持一个 Bot 和一个云服务器绑定。左侧是 Bot 会话列表，右上角用一个轻量的“同步模型”按钮打开本机模型选择面板。输入框下方的模型和目录只属于当前会话。

## 交互约定

- 同步由用户主动触发。本机编辑模型不会自动上传；未勾选也不删除云端已有配置。账号登录和仅本机可达的接口明确显示原因。
- 云端保存独立模型副本，确认前不显示成功。同步中断先展示结果待核对，重连后取回云端结果。
- 新会话继承 Bot 默认模型和默认空间。各会话分别保存消息、草稿、模型和目录；切换不会取消原任务。
- 目录选择器打开即读取当前云服务器的当前层文件夹，点击逐级浏览，不必手填路径。原型以异步演示数据表现加载、空目录、失败重试和过期响应丢弃；真实版通过已认证的 Host／SSH 获取目录。点击“使用此文件夹”才提交，取消或无权限不修改原绑定。
- 选择器不再重复显示“已校验文件夹”和历史文件归属说明，路径在顶部显示。
- Bot 队列串行执行，任务受理时固定所属会话、模型版本和目录。本原型用锁定输入区模型与目录简化演示；正式实现按需求 1.2 复用普通对话的后续输入及队列规则，后续选择不修改已受理快照。
- 同步更新或更换目录不改写旧任务、授权和历史交付物位置。后台完成不会抢回另一条会话。
- 多会话使用同一个默认空间时共享其中的文件，不暗示独立文件系统。

## 视觉与验证

沿用 Hemi 经典皮肤、系统字体、48px 导航、224px 会话栏、52px 顶栏和 720px 阅读列。新增样式引用现有 token；小型同步按钮保持次要层级。窄窗口保留同步图标和模型、目录控件，会话列表收进抽屉。

在项目根目录运行 `node docs/design/cloud-bot/v2/verify.mjs` 可复现交互检查与截图。使用现有 `playwright-core` 和本机 Chrome，不增加依赖；测试浏览器完成后关闭。

[验证记录](exports/validation.json) 包含代码基线、7 个被测源文件 SHA-256、15 项检查、43 张截图与错误记录。画面覆盖 1440×900、1180×720、768×1024、375×812；经典皮肤没有独立深色版。本轮只验证视觉与模拟交互，真实云端服务和模型仍需开发验收。
