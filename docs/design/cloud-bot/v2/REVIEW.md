## 问题与最终处理

| 级别 | 问题 | 最终处理 |
| --- | --- | --- |
| P2 | 已同步条目默认全选，缺少本次上传范围说明 | 默认只选新增或有更新的模型；动态列出模型及接口、型号、API Key；未勾选不删除云端配置 |
| P2 | 同步断线后弹窗关闭，结果待核对不可见 | 离线横幅持续显示待核对；重连后显示云端确认，早于确认时仍等待 |
| P2 | 地址栏输入未经校验，却能提交旧目录 | 输入与已校验路径不同时禁止提交；展示云端确认中，收到确认前保持旧绑定；增加最近目录 |
| P2 | 离线仍能模拟下载云端文件 | 用缓存记录展示路径；下载按钮及处理器同时拦截；离线隐藏正文预览 |
| P3 | 模型身份和名称依赖本机展示数据 | 使用 providerId/modelId；云端保存独立模型元数据，任务冻结模型名称及目录标签 |
| P3 | 账号授权文案暗示已有入口 | 明确首版暂不支持账号登录同步及云端授权，本机地址不可用单独说明 |
| P3 | 会话状态和窄窗连接状态缺少可读名称 | 为会话补 aria-label/title；顶栏统计所有会话等待确认数量，窄窗保留可访问名称 |
| P3 | 更换目录提示的位置可能误解为改变旧任务 | 按用户反馈删除选择器底部重复说明及目录切换后的时间线提示，由系统保持任务与交付物归属 |
| P3 | 窄窗目录快捷入口拥挤 | 缩短“主目录”、调整 token 间距、允许换行；核对展开菜单边界，完整路径在顶部输入框中可查看并提供 title |

## 目录选择补充

按用户反馈删除“已校验文件夹”及“不移动原目录文件或历史交付物”的整块说明。选择器保留服务器、路径、快捷入口、文件夹列表和使用操作；打开即加载当前层，支持逐级进入和上级返回。真实版通过受认证 Host／SSH 读取目录；本稿继续使用明确标注的异步演示数据。

补充检查覆盖加载中禁止提交、空目录、权限错误、临时失败重试、快速导航、在途关闭与断线，以及进入下一层后的焦点。路径提示只在用户主动编辑后出现；读取期间不闪现提示。375px 下正常列表、加载和失败的弹窗高度同为 430px。

第二轮提出的非阻断细节留给正式组件细化：背景任务触发整页重绘或加载期间继续输入时的焦点保持，以及从根目录进入子目录时上级按钮的加载态。这些没有被记录为已验证通过的生产行为。
