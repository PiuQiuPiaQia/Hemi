# Hemi Bot 交互稿 v3

日期：2026-10-22。依据：[需求 1.2](../../../requirements/cloud-bot.md) 与[普通对话复用约定](../conversation-reuse.md)。

本版按普通对话页更新：直接加载当前工作区真实的 React 对话组件及产品样式，用独立的演示适配层提供 Bot 数据。消息、会话列表、输入区、模型选择、思考强度、队列、文件预览和用量沿用现有组件。生产源文件及依赖均未改动。

- [当前预览（待 cc 评审）](http://127.0.0.1:62552/?state=complete)
- [首次创建连接](http://127.0.0.1:62552/?state=welcome)
- [带场景切换工具的评审页面](http://127.0.0.1:62552/?state=complete&tools=1)
- [普通对话对照](http://127.0.0.1:62552/?state=ordinary)

点击左侧 Bot 图标进入云端对话；点击普通对话图标可对照共用布局。可体验新建／切换／重命名／删除会话、历史列表、独立草稿、编辑重发、失败重试、附件、`/model`、`@`、思考强度、继续输入与队列编辑。历史沿用当前产品的列表，没有额外添加搜索。

Bot 只补充以下场景差异：

| 位置 | Bot 交互 |
| --- | --- |
| 左侧导航 | 独立 Bot Tab；未绑定时进入连接与初始化引导 |
| 顶部 | 连接状态、小型“同步模型”按钮、Bot 设置 |
| 模型选择 | 从手动同步并经云端确认的目录选择；同步可见范围及不支持的认证原因 |
| 原目录入口 | 直接浏览服务器文件夹、逐级进入、上级返回、输入路径、错误重试 |
| 消息与输入 | 保留通用文字交互；附件先上传就绪、引用查云端资源、交付物保留所属路径 |
| 权限与常驻 | 云端授权、停止／启动、断线缓存及重连核对 |
| 语音 | Bot 隐藏通话及相关入口；普通对话对照保留原有入口 |

没有“已校验文件夹”及“不移动原目录文件或历史交付物”的重复说明。

## 运行与文件

开发预览：`node docs/design/cloud-bot/v3/serve.mjs`。构建：`node node_modules/vite/bin/vite.js build --config docs/design/cloud-bot/v3/vite.config.mjs`，输出位于 `.visual/workflow/bot-v3-built`。可使用任意本地静态 HTTP 服务打开构建产物。

- `main.jsx`：真实产品组件与 Bot 能力入口。
- `store.js`：独立内存适配器、演示 Host 状态与本机桥接桩。
- `bot-panels.jsx`：Bot 差异弹窗及连接引导。
- `prototype.css`：仅追加差异与评审工具样式，颜色使用产品 token。
- `verify.mjs`：[检查记录与源文件哈希](exports/validation.json)；脚本退出时关闭验证浏览器。
- [评审记录](REVIEW.md)：Claude Code 对本版的只读评审结论。

第三方组件与字体沿用项目已有依赖，版权及许可见仓库 [THIRD-PARTY-NOTICES.md](../../../../THIRD-PARTY-NOTICES.md)。

## 交互稿边界

数据、SSH 指纹、初始化进度、模型同步、目录列表、上传、运行事件、授权及文件内容均为演示数据；不会接入真实云服务器、读取附件正文、同步密钥、调用模型或启动麦克风。模拟 Host 在页面内存中持续运行，刷新会重置；常驻服务、SSH、SDK、真实 IPC、真实认证与文件传输仍属于后续实现。

本稿保留当前产品的交互与外观，适配层只演示主要路径，不能当作真实云端全功能验收。正式开发仍需将组件的数据与能力从本机桥接解耦，具体约定见复用文档。
