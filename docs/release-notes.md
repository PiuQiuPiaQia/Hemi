本次发版接入 Windows 原生标题栏控制，并打通 Windows 本地桌面能力与应用授权。

- Windows 窗口改用原生最小化、最大化和关闭控制，与应用内导航自然衔接。
- 启动时探测交互式桌面与原生驱动，接通 Windows 应用发现与启动身份，就绪和错误状态显示准确；键盘输入投递与快捷键仍有已知限制。

本次桌面发行提供 macOS（Apple 芯片）DMG 和 ZIP 更新包。Windows 桌面能力随源码同步，本次不包含 Windows 安装包发布。

---

This release integrates native Windows caption controls and enables local desktop capability with application authorization on Windows.

- Windows windows use native minimize, maximize, and close controls that follow in-app navigation.
- On startup the interactive desktop and native driver are probed, Windows app discovery and launch identities are connected, and ready and error states are shown accurately. Keyboard input delivery and hotkeys still have known limitations.

The desktop release includes macOS Apple Silicon DMG and ZIP packages. Windows desktop capability ships with the source; this release does not include Windows installers.
