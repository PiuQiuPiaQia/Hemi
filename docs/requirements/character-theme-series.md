# Hemi 人物主题需求入口

更新日期：2026-10-21。

人物主题的视觉、交互、资源、技术边界和验收标准已合并至 [Hemi 人物主题与换肤功能需求文档](appearance-and-skins.md)。该文档是本次开发的统一依据。

最终方案为经典与五款人物皮肤、设置按钮上方的换肤入口、两列人物卡片，以及不占列表空间的固定人物背景。人物与配色一起切换，不提供独立人物背景开关。

此前的独立布局概念、按会话空白显隐人物和带背景开关的浮层均已被最终方案替代，不作为实施基线。
