Hemi 增加独立的 Bot 页面，让用户连接一台自己的 Linux 云服务器，并在引导中安装和初始化常驻 Bot。云服务器承载 Agent、模型请求和任务执行；本机 Hemi 用于发送指令、处理确认和查看结果。关闭本机 Hemi 或断开 SSH 连接后，云端已受理的任务继续推进，直到完成、发生错误、达到运行限制或进入等待新授权的状态。

首次使用的主线是“打开 Bot → 创建连接 → 选择本机模型并初始化 → 开始对话”。一个 Bot 可以创建多个独立会话；新会话使用云端默认空间，也可以选择当前云服务器上的其他文件夹。产品不增加 Bot 列表、主机列表或角色管理。

配套设计：[普通对话复用约定](../design/cloud-bot/conversation-reuse.md)、[共用普通对话组件的交互稿 v3](../design/cloud-bot/v3/README.md)、[v3 视觉评审记录](../design/cloud-bot/v3/REVIEW.md)。v3 使用真实页面组件与演示适配数据；完整功能要求与验收以本文为准。

## 1 目标与范围

### 1.1 用户已确认的要求

| 要求 | 产品约束 |
| --- | --- |
| 单个 Bot | 当前 Hemi 配置只管理一个 Bot 绑定，绑定不属于某条普通对话 |
| 一台云服务器 | Bot 的运行主机是用户通过 SSH 接入的 Linux 云服务器 |
| 独立入口 | 左侧导航增加与对话、技能中心、工作流平级的 Bot Tab |
| 首次引导 | 未绑定时直接引导创建连接和初始化，不展示空的管理列表 |
| 云端常驻 | 云端安装运行组件，由独立服务承载 Bot；SSH 会话与本机窗口不承担 Bot 生命周期 |
| 模型来源与同步入口 | 本机模型列表是配置来源，Bot 页面顶部提供小型“同步模型”入口，由用户手动同步 |
| 多会话 | 一个 Bot 下可创建和切换不同会话，各自保存消息、草稿、任务、所选模型与运行目录 |
| 云端空间 | 新会话默认使用云端默认空间；每个会话可浏览并选择当前云服务器上的文件夹 |
| 对话功能复用 | 与普通对话共用页面组件和通用交互，保留现有非语音对话功能；按 Bot 场景关闭语音相关能力，适配云端数据与工具 |

“只管理一个绑定”约束本机产品入口，不承诺自动发现或停止其他机器上独立安装的 Bot。

### 1.2 本版建议默认值

以下为本草案的首版方案，不属于用户逐项确认的附加要求。

| 项目 | 首版默认方案 |
| --- | --- |
| Bot 身份 | 默认名称为 Hemi Bot，不要求填写角色、人设或头像 |
| 对话 | 普通对话是通用功能基线，共用会话列表、消息流与输入组件；默认按 Bot 队列串行执行任务，切换会话不停止后台任务 |
| 云端环境 | 以 Linux + systemd 为首个落地环境；发行版、CPU 架构和安装包支持矩阵在技术方案中冻结，初始化只放行已验收组合 |
| 云端工具 | 文件读取与修改、目录检索、命令执行；工具只能操作云端授权范围 |
| 模型配置 | 用户手动选择本机模型并同步，云端保存独立可用副本；首版支持 API Key 配置，账号登录类明确显示需云端授权 |
| 文件交付 | 支持查看云端交付文件的信息、下载，并复用本机已有的格式预览能力 |
| 输入 | 保留文字、附件选择、拖入文件和粘贴图片等普通对话输入；所选附件传到云端后才可随消息使用。Bot 关闭语音输入、实时通话、语音播报及录音相关入口 |
| 连接通道 | SSH 用于探测、部署、维护及建立控制通道，不要求用户开放额外公网服务端口 |

首版不纳入多个 Bot、多主机管理、多桌面协同、定时任务、Webhook、外部聊天渠道、独立 Web 控制台、云端浏览器和图形桌面接管。常驻表示服务持续可用、任务可脱离本机运行；空闲时不自动调用模型。后续增加云端工具能力时，仍须保持执行位置和权限边界清晰。

### 1.3 与现有 SSH 工作区的区别

| 维度 | 现有 SSH 工作区 | 云端 Bot |
| --- | --- | --- |
| Agent 执行循环 | 本机 Hemi | 云服务器 |
| 文件与命令 | 通过 SSH 在服务器执行 | 由云端运行组件在服务器执行 |
| 模型请求 | 本机发起 | 云端独立发起 |
| 浏览器和桌面 | 按现有能力在本机执行 | 首版不提供，也不回退到本机执行 |
| 会话与任务状态 | 本机服务管理 | 云端保存权威状态，本机同步展示 |
| 本机退出或断网 | 不能继续推进本机 Agent 循环 | 已受理且无需新增确认的任务继续 |

现有 SSH 工作区入口和行为继续保留。创建普通 SSH 工作区不会自动安装 Bot，也不会自动获得云端常驻能力。

## 2 页面与首次使用流程

### 2.1 左侧 Bot Tab

导航名称、悬停提示和无障碍名称统一为“Bot”。沿用现有导航尺寸、皮肤、焦点和选中态规则；入口放在应用页面导航区，不放入底部设置区。

| 当前情况 | 打开 Tab 后的页面 |
| --- | --- |
| 尚未创建连接 | 首次引导页 |
| 初始化未完成 | 恢复到当前步骤，显示已完成项与待处理项 |
| 已绑定且可连接 | Bot 对话页，同步云端状态 |
| 已绑定但连接中断 | 保留 Bot 对话页，展示已缓存记录及重新连接入口 |
| 已确认云端 Bot 停止 | 保留对话页，提供“启动 Bot” |

切换 Tab、关闭窗口或重载 renderer 不应重复创建 Bot，也不停止云端任务。普通对话和 Bot 的草稿、执行状态与文件位置相互隔离。

### 2.2 首次引导页

标题：“让 Hemi 在云服务器上持续工作”。说明：“连接并初始化后，即使关闭本机 Hemi，Bot 也能继续执行已受理的任务。”主按钮：“创建连接”。

页面不要求用户先创建 Bot 名称、选择角色或阅读 SDK 文档。尚未配置时，不显示不可用的聊天输入框。

### 2.3 连接与初始化向导

| 步骤 | 用户操作 | 系统行为 | 完成条件 |
| --- | --- | --- | --- |
| 连接服务器 | 输入 SSH 地址或已有 Host 别名，选择认证方式 | 验证身份并检查主机环境，发现已有安装 | SSH 身份与目标主机可信，环境检测通过 |
| 配置 Bot | 选择要同步的本机模型 | 复用页面顶部的同步入口，检查模型计划与目录权限 | 至少选择一个可独立在云端使用的模型 |
| 初始化 | 点击“初始化 Bot” | 部署运行组件、保存云端配置、注册常驻服务、启动并验证 | 所有初始化检查通过，本机绑定保存成功 |
| 开始使用 | 进入 Bot 会话页，可新建会话和选择云端目录 | 获取云端会话、模型目录与任务状态 | 可以在选定模型与目录下发送任务 |

步骤内自动完成可检测的工作，不把命令行操作作为常规安装流程。遇到必须由主机管理员处理的条件时，显示具体原因、修复方式与“重新检测”，保留前面已经填写的非敏感配置。

## 3 功能要求

### R-01 SSH 连接与主机检测

复用现有 SSH 配置、密钥或 SSH agent、密码认证能力；连接表单应明确实际使用的主机身份。自定义端口等连接选项遵循既有 SSH 配置，不在首版重新建立完整 SSH 配置管理器。

首次信任主机需展示可核对的指纹并由用户确认，或接入既有可信主机记录。指纹变化必须阻断自动部署和重新绑定，不通过关闭主机校验解决连接失败。认证失败、超时、网络不可达与主机身份冲突使用不同文案。

检测内容包括系统与 CPU 架构、安装目录和工作目录权限、磁盘空间、必要的运行依赖、服务管理能力、退出登录后的驻留条件、开机启动条件及已有 Hemi Host 的身份和版本。不支持的环境应在安装前说明。

首版 systemd 方案必须处理用户级服务退出登录后的驻留和开机启动条件；条件不满足时不能降级成依赖 SSH 会话的临时进程并宣称初始化成功。需要额外主机管理权限时说明用途，不暗中提权或修改无关系统设置。

### R-02 初始化模型与默认空间

Bot 的模型配置以本机模型列表为来源，不再要求在 Bot 内重建一套供应商表单。初始化时通过“选择本机模型”打开与页面顶部“同步模型”相同的选择器，选择需要同步的模型；勾选支持点击整行、复选框和键盘操作，不因行内焦点变化收起列表。提交前说明接口、型号及所选模型必需的 API Key 将保存到云服务器；初始化完成后，该副本可脱离本机独立调用。完整同步规则见 R-13。

初始化必须从云端验证所选模型，至少有一个验证通过，不能以本机测试成功代替云端连通性。账号登录、缺少凭据或仅本机可达的模型需展示各自原因，不误报为已同步可用；未完成云端认证的模型不能被会话选用。

为 Bot 建立当前云端账号可写的默认空间，独立于会话档案与凭据目录。默认空间由 Bot 自动创建并内置提供，初始化不再要求选择目录。新会话继承该默认空间，每个会话可以再选择其他云端目录，规则见 R-14、R-15。

初始化与 Bot 设置不提供全局默认模型或默认空间配置。与本地对话一致，新会话沿用最近打开或选择的云端模型；首次使用自动采用已验证的可用模型。每条会话保留自己的模型和目录，修改一条会话不改变其他会话。

### R-03 部署与初始化完成判定

用户安装的是“Hemi 云端运行组件”，内部由独立的 Hemi Host 服务承载运行核心。产品不要求用户区分 SDK 和服务，也不要求手工安装 npm 依赖或打开完整桌面应用。

Hemi 负责部署匹配平台且可校验来源与完整性的运行组件及必要运行环境；安装位置与数据位置分离，不覆盖用户全局 Node、Shell 配置或已有项目依赖。是否内置全部平台安装包、使用何种交付渠道由技术方案决定。

初始化应展示真实阶段，例如检测环境、部署组件、保存配置、配置常驻、启动验证。无法计算真实进度时使用阶段状态，不显示虚构百分比。

只有同时满足以下条件，才显示“初始化完成”并进入可用状态：

1. 独立服务启动成功；实际关闭本次 SSH 控制会话并重连后，确认服务实例未退出或重建，已保存的任务状态仍可读取。
2. 云端实例身份已生成并验证，控制通道健康，协议版本兼容。
3. 模型从云端完成最小真实请求，返回有效结果。
4. 云端工作目录内完成可清理的真实文件与命令验证。
5. 开机启动和退出登录后驻留的必要配置核对通过，非敏感的初始化状态及单 Bot 绑定已成功保存；敏感配置按 R-12 处理。

常规初始化不重启用户服务器。退出 SSH 后驻留需要实测；开机启动在向导中核对配置，真实重启后的行为在专用验收主机验证，两者不能混为已经实测。断开验证只影响 Bot 本次建立的连接，不能关闭普通 SSH 工作区、其他任务或用户终端的连接。

测试文件只能位于本次创建的验证目录中，不能修改用户已有项目文件。模型验证使用短请求，并在初始化说明中告知会产生一次模型调用。

### R-04 初始化重试与取消

初始化各阶段必须可检测、可重入，并有针对同一安装的并发保护。重复点击、renderer 重载、本机重启或网络恢复后，先检测远端实际进度，不生成第二个实例、第二份服务或第二次配置写入。

已有绑定且实例身份一致、版本兼容时复用；移除绑定后重新连接同一服务器，也应识别原实例，经用户选择“连接已有 Bot”恢复绑定和记录，不重复安装。可升级版本提示维护操作；身份不一致、来源不明或协议不兼容时停止覆盖并给出处理方式。不删除旧实例数据来绕过冲突。

失败页面保留已完成阶段、失败原因和重试入口。取消只终止本次未完成的初始化工作，并清理本次临时资源；已完成的云端安装或服务不得被误报为不存在。连接丢失导致结果未知时显示“需要重新检测”，不推断取消成功。

本机绑定保存失败但云端已初始化时，恢复流程应重新识别同一实例并补存绑定，不能重新安装一个 Bot。

### R-05 初始化后的 Bot 会话页

页面保留左侧应用导航，使用普通对话的同一套会话列表、消息流和输入区，数据来源切换到当前 Bot。顶部保留当前会话，并增加连接状态、小型“同步模型”入口和 Bot 设置；服务器身份清楚可见。中部沿用消息、执行过程、权限请求和交付物组件；输入区保留现有非语音工具栏，模型选择读取 Bot 可用模型，目录选择浏览云端文件夹。通用功能基线及复用方式见 R-16。

顶部状态从真实连接、服务和任务状态组合得出，不能只以 SSH 进程是否存在判断 Bot 是否正在运行。设置集中提供模型和工作目录配置、诊断，以及 R-11 定义的维护操作。

Bot 页面关闭语音输入、实时通话、录音、语音播报和相应快捷键；不展示语音配置修复条或占位按钮。依赖本机窗口、屏幕、录屏、浏览器或桌面采集的入口按云端能力隐藏。附件等通用文本对话能力属于实现范围，不再因 Bot 场景默认删除；界面与工具清单只展示实际可用的能力。

### R-06 执行位置与任务受理

Agent 循环、模型请求、工具执行、任务队列和执行记录均属于云端。即使本机 Hemi 退出，也不依赖本机代理模型请求、继续工具执行或保存任务状态。

Bot 的文件与命令工具按照服务器身份和路径解析。缺少云端能力时明确报告，不能把命令、文件操作或其他工具偷偷切回本机。普通 SSH 工作区用于说明混合执行位置的提示词不能直接用作 Bot 提示词。

用户每次提交指令都带稳定的请求身份，云端持久受理后才显示“已受理”。同一请求重复提交、网络重试或回执丢失，不得重复创建任务和执行动作。受理结果未知时先查询、对账；不能换一个新请求身份自动重发。

首版按 Bot 队列顺序处理已受理任务。多个会话可以分别提交任务，等待项明确显示“排队中”及所属会话；切换会话不停止原任务。受理时冻结会话身份、模型配置版本、云端目录和授权范围，排队期间也不能被其他会话的修改覆盖。

同一会话执行中可继续写下一条，并按普通对话规则加入待发送队列、编辑或取消排队项。界面分别表达未受理草稿、待发送项与云端已受理任务；失联时仍遵循 R-08，不另建离线发送队列。停止当前回合、停止所属任务与停止 Bot 服务使用不同动作，沿用普通对话已明确的停止语义。

### R-07 常驻与中断恢复

本机退出、关闭窗口、切换 Tab、关闭控制通道或本机断网，不改变已受理任务的云端生命周期。任务具备所需授权且云端模型和主机可用时应继续，完成后将结果保存到云端。

云主机重启或 Host 异常退出后，服务按已保存的启停设置恢复。此前正在运行的任务应说明中断和最后已知进度，不能直接标记为成功。未确认执行结果的有副作用操作不自动重放；人工选择继续时也需先核对已完成部分。

本版不承诺任意运行中任务在进程崩溃后无缝续跑。等待授权的任务可恢复等待；尚未开始的已受理任务，在完成状态核对且 Bot 处于启用状态后按原顺序处理。

空闲服务不轮询模型、不生成自发任务。任务受现有运行限制约束，达到限制时记录原因并停止推进，不形成无限模型调用循环。

### R-08 连接中断与记录同步

连接中断后保留已经同步的对话和交付物信息，展示最后同步时间及“重新连接”。网络恢复时可进行有退避的有限重试，用户仍可主动重试；认证、指纹和身份冲突不应无限自动重试。

失联文案应表达“连接已断开，云端可能仍在运行”，不展示未经确认的“Bot 已停止”或“任务已失败”。旧记录标明为最近同步状态。

重连后以云端快照及后续事件为准，补齐本机离线期间的消息、任务结果、权限请求和交付登记。允许重新获取完整状态，不要求客户端永久持有全部事件；重复或迟到事件不能产生重复消息或回退任务状态。

断线期间不新增离线任务队列：输入保留为草稿，发送入口说明需要恢复连接。断线前受理状态未知的指令保留为待核对，不与未发送草稿混淆。

### R-09 云端权限与等待确认

云端服务独立执行 Hemi 的访问范围和动作分级规则。初始化展示授权摘要：允许访问所选工作目录，目录内文件操作及命令是否自动执行仍按 Hemi 现有动作分级处理；需要确认的动作不会因“常驻”自动放行。不默认允许访问全机、敏感凭据或所有危险命令。

已有授权范围内的操作可以继续；需要新增确认的动作必须先保存待确认请求，并让相关任务进入等待状态。本机离线不能导致自动同意、自动拒绝或授权请求丢失，也不能让同一动作在重连后重复执行。

用户重连后可以允许或拒绝；提交时核对请求仍有效且属于当前任务。等待期间任务被停止、运行被中断或配置变化导致请求失效时，旧授权卡不可继续批准。

云端运行账号、文件访问边界及权限记录与本机分开。首版不因复用已有 SSH 登录而把本机已授予权限复制到服务器。

### R-10 云端交付文件

任务可以登记其受理时云端工作目录中的文件为交付物，记录所属会话、主机及实际路径，展示文件名、类型和可用性。会话之后切换目录不重写旧交付物的位置。点击下载时通过受认证的连接读取真实云端文件，不能把远端路径作为本机路径打开。

已有本机预览器支持的格式可以在下载后预览；其余格式提供下载和文件信息，不承诺所有格式都有预览。下载属于显式用户操作，默认不把整个工作区或全部云端文件同步到本机。

断线、文件删除、内容变化和无权限应提供相应反馈，不能将缓存条目误报为文件仍可用。大文件使用既有或明确公布的大小限制，下载可取消，不阻塞主对话。

### R-11 维护操作与单 Bot 绑定

| 操作 | 应有行为 |
| --- | --- |
| 停止当前任务 | 请求云端取消当前任务；资源实际退出后显示停止完成，服务仍可接收后续任务 |
| 断开连接 | 关闭本机控制连接，保留绑定、记录和云端服务；不停止任务 |
| 重新连接 | 连接原有实例并核对身份，不重装或重复提交旧任务 |
| 停止 Bot | 明示将中断当前任务，停止云端服务并保存停用设置；主机重启后不擅自恢复运行 |
| 启动 Bot | 恢复云端服务和常驻设置，核对历史中断状态；不自动重放有副作用的动作 |
| 移除连接 | 仅删除本机绑定；操作前说明云端服务、任务、数据和模型凭据都会保留；提供“停止后移除”选项，只有确认停止成功才完成该选项 |
| 修改连接地址 | 仍需核对原实例身份；地址变化不等于创建新 Bot |

停止操作按真实回执展示“停止中”“已停止”或“结果未知”。失联时不能声称已成功停止；应保留待核对状态，并说明无法确认云端结果。

服务器身份与 Bot 实例身份共同确定绑定。同一 IP 重装系统、切换机器、出现不同实例身份时，不静默接管或覆盖。已有绑定时不提供“再添加一个 Bot”；更换运行主机需要显式移除原绑定并重新引导，不自动迁移旧会话、凭据和任务。

移除绑定后，Bot Tab 回到首次引导。原 Bot 的本机草稿与缓存不能归属新连接；不因移除 Bot 删除普通工作区共用的 SSH 配置或凭据。

本版不提供删除云端数据或完整卸载器。移除页面需告知云端安装与凭据的位置，并提供对应版本的手动清理说明；本机忘记连接不等于撤销云端模型凭据。移除绑定后的旧实例可能仍在运行，界面不得宣称全局只剩一个 Bot。

### R-12 凭据、版本与诊断

云端服务不直接监听公网控制端口；本机通过 SSH 建立受认证的控制通道。仅使用服务器回环地址或受权限保护的本地套接字仍需约束同机其他账号的访问。

SSH 私钥保持由本机 SSH 管理，不上传到服务器。密码遵循现有本地保存规则。云端模型凭据仅按用户选择传输，保存为受账号权限和适用加密机制保护的数据；凭据文件权限限定为当前运行账号可访问，不回传到 renderer、消息、诊断导出或日志。

正常显示云端模型连接状态，不重新下载模型密钥。清除输入框、切换 Tab 或查看配置不触发凭据全量同步；修改云端凭据只影响云端 Bot。

每次连接进行桌面端、Host 与协议能力握手。兼容版本正常使用；不兼容时显示明确原因和维护入口，禁止新任务提交。版本维护默认等到云端空闲；需要中断在途任务时，先说明影响并由用户选择。升级失败应能恢复原版本和原数据，不能重置 Bot 作为升级手段。

诊断包括组件版本、主机环境、最后连接时间、当前服务状态、最近失败阶段及已脱敏日志。导出不包含模型密钥、SSH 密码、令牌、整段个人对话或工作目录文件。

### R-13 页面顶部手动同步模型

在 Bot 页右上角提供带同步图标的小型“同步模型”按钮，不占用独立导航页，也不为每个会话重复建立供应商配置。服务器未连接时说明需先连接；失联时不可宣称同步成功。

点击打开本机模型选择面板，按供应商、名称和认证方式展示模型，并区分“已同步”“有更新”“未同步”“需云端授权”“缺少凭据”或“云端地址待配置”。用户手动选择本次新增或更新的模型，查看同步范围后提交。未勾选不自动删除已经在 Bot 保存的模型；本机删除或退出账号也不被当成已经撤销云端凭据。

同步只发送选中模型所需的定义、能力及可支持的认证配置，不上传整份本机配置、其他供应商密钥或会话记录。云端核对稳定模型身份和配置版本，验证后回传结果；本机展示云端实际确认的可用目录，而不是点击后立即标为成功。失败项说明原因，保留其原来已验证的配置；至少保留一个可用模型。

API Key 可以在用户明确同步时写入云端。账号登录类可以同步型号信息，但认证与刷新必须由云端独立完成；没有交付相应云端授权能力时明确显示不可用，不复制本机令牌冒充普通 Key。本机回环地址、局域网或代理地址需按云端视角验证，不静默转成本机转发。

同步为用户主动操作，不随本机列表编辑自动执行。修改、更新或撤销云端配置不得改变在途任务已冻结的模型版本。会话仅能选择云端已同步并验证可用的模型；模型失效时保留原引用并要求修复，不自动替换到别的供应商。

### R-14 多会话与各自模型

Bot 下支持新建与切换会话。新会话沿用最近打开或选择的云端模型，并使用内置默认空间，消息、草稿、任务、权限请求、运行目录及模型选择以独立会话 ID 保存。切换、重连和 renderer 重载按所属会话恢复，异步返回不能写入当前打开的另一条会话。

会话列表展示执行中、排队中和等待确认状态；离开会话不取消任务。不同会话引用同一份 Bot 可用模型目录，但可以各选一个模型。修改当前会话模型不改变 Bot 默认值或其他会话。输入区后续指令的模型、目录和排队项沿用普通对话规则；已受理任务始终使用自己的冻结快照，不因后续选择而变化。会话当前选择与每条任务的实际执行配置分别记录和展示。

Bot 的模型和会话档案由云端持久化，本机只维护展示缓存。多个会话使用默认空间时可以访问同一个目录；会话内容独立不等于自动建立文件系统隔离。首版通过队列串行推进，避免无提示的并行写入。

### R-15 每会话选择云端文件夹

当前会话的运行目录选择器默认显示“默认空间”。点击即打开当前 Bot 所在服务器的文件夹选择器，自动读取当前会话目录下的文件夹列表，不要求用户先手工输入路径。支持点文件夹逐级进入、上级导航，以及默认空间、主目录和最近使用的目录快捷入口；手动输入远端路径是辅助方式。不打开本机文件选择器，也不在这里切换 SSH 主机。

目录列表通过已认证的 Host／SSH 通道读取当前服务器的真实文件系统，每次进入目录按需获取当前层文件夹；不使用本机目录、固定路径模板或演示清单代替真实数据，也不递归扫描全机。主目录从云端账号探测结果取得。列表需要区分加载中、空目录、无权限、目录不存在与读取失败，失败可重试；快速切换或关闭弹窗后，旧请求结果不能覆盖新位置。失联时不展示缓存列表为实时可用目录。

选择器只保留服务器身份、当前路径、目录列表和取消／使用操作；不重复展示“已校验文件夹”及“不移动原文件或历史交付物”等常驻说明。目录检查与历史归属规则由系统保证。

选择目录先在服务器上验证存在性、真实路径和所需权限；用户点击“使用此文件夹”并收到云端确认后，才更新当前会话。仅浏览不等于授予访问权。目录授权沿用 Hemi 的范围和动作分级规则，不因选中父目录就放开敏感文件或危险操作。

新目录仅作用于当前会话后续受理的任务，不改变其他会话、既有任务、原目录文件或历史交付物。界面显示目录名称并可查看完整云端路径。目录失效、无权限或失联时保留原绑定并显示修复入口，禁止静默退回默认空间或本机路径。

### R-16 普通对话作为功能基线

Bot 使用同一个对话页面及组件体系，通过运行环境和能力配置提供差异，不维护一套独立精简版。以下现有通用功能纳入 Bot 范围；布局、快捷键、空态、错误提示和确认方式沿用普通对话。后续新增的通用对话功能默认在共享层实现，并在两种环境验收，只有明确的运行环境依赖才形成差异。

| 功能 | Bot 中的要求 |
| --- | --- |
| 会话管理 | 新建、切换、历史查看、重命名、删除、复制会话 ID，以及现有时间分组、排序和窄窗抽屉；操作当前 Bot 的云端会话，不混入本机会话 |
| 消息与结果 | 相同的 Markdown、代码与复制、用户消息编辑重新发送、失败重试、过程折叠、任务状态、授权卡和交付物展示 |
| 输入与队列 | 相同的文字编辑、发送／换行、草稿、输入历史、待发送项编辑／取消及停止交互；运行与受理状态由云端确认 |
| 附件 | 保留选文件、拖入和粘贴图片、预览与移除；显式选择的内容传到 Bot 后使用，不能把本机绝对路径当作云端文件 |
| 上下文与能力 | 保留记忆提示、`/`、`@`、模型、思考强度、访问范围和用量等现有交互；目录、引用、技能、权限与统计取自当前 Bot 的运行环境 |

附件沿用既有格式、大小与模型能力限制。显示上传进度、失败重试和取消状态；附件在云端就绪并取得稳定身份后，才能与消息一起提交。断线、取消或传输失败保留草稿，不误报附件可用，不自动改为上传整个本机目录。图片输入不等于启用截图、录屏或语音采集。

`@` 文件和目录查当前 Bot 授权范围，`@` 会话查当前 Bot 的会话；交付物沿用所属运行记录。`/model` 与输入区模型选择读取同一份 Bot 可用目录。技能及工作流等候选保留同样的选择交互，但执行依赖和资源必须在云端可用；不能把本机安装、会话、应用窗口或本机权限当作 Bot 已具备。尚不可用的云端候选说明原因，不静默改成本机执行，也不因页面复用就自动同步全部本机配置。

消息编辑重发、失败重试、队列编辑及删除会话沿用普通对话的操作语义，由云端执行状态变更。编辑回卷要终止或作废原回合，按服务器确认的代次过滤迟到事件；不能在本机改掉显示后又被云端旧消息补回。重连本身不触发新的重发；删除或停止也不能伪装成撤销已经发生的云端文件与外部副作用。

语音能力按 Bot 环境禁用，不启动麦克风、ASR、实时通话、TTS、录音或录屏会话，相应全局快捷键不能在 Bot 页面触发这些采集。普通对话的原有语音设置与使用不受影响。仅隐藏图标不足以完成该要求。

## 4 状态表达

初始化状态、连接状态、服务状态和任务状态分开记录，再组合为界面文案。连接中断不会自动修改云端任务终态。

| 场景 | 主要展示 | 可用动作 |
| --- | --- | --- |
| 无绑定 | 尚未连接云服务器 | 创建连接 |
| 初始化中 | 当前阶段及已完成项 | 取消；按实际阶段限制返回修改 |
| 初始化失败 | 失败阶段和具体原因 | 重试、修改配置、重新检测 |
| 已连接且空闲 | 已连接 · 待命 | 发送指令、设置 |
| 已连接且有任务 | 执行中或等待确认 | 继续输入与排队、查看过程、确认、停止当前任务 |
| 控制连接中断 | 连接已断开 · 云端状态未知，显示最后同步时间 | 重新连接、保留草稿 |
| SSH 可达且确认服务停用 | Bot 已停止 | 启动 Bot |
| 任务因主机或服务重启中断 | 已中断，展示最后进度 | 查看原因、核对后继续 |
| 身份冲突或版本不兼容 | 需要处理，说明原因 | 查看详情、维护；禁止发送任务 |

## 6 实现约束与验证要求

### 6.1 云端运行核心

必须先抽出不依赖 Electron 生命周期、窗口、renderer IPC 或本机配置单例的运行核心。桌面端与 Host 通过明确的宿主接口提供数据目录、配置、凭据、权限、日志和工具能力；不能把现有桌面主进程复制到服务器并依赖其隐藏窗口维持工作。

SDK 是可复用运行能力的内部组织方式，Host 是真正的常驻进程。本次不要求公开发布第三方开发者 SDK、稳定外部编程 API 或独立云平台。

云端持久化会话、任务受理记录、运行结果、待确认请求和交付登记。本机保存一个绑定及必要展示缓存，不能与云端形成互相覆盖的两套权威状态。

桌面对话组件通过运行环境适配层接收会话、消息、队列、附件、候选、权限、模型和用量数据。当前直接调用本机 IPC／单例的组件需先解耦数据来源，再由普通对话适配本机、Bot 适配云端；不能只传一个隐藏语音的布尔值却继续操作本机会话存储，也不能复制一份页面后分别维护通用逻辑。

部署与核心能力分层验证：SSH mock 只能证明本机通道边界，不能替代真实 Linux 主机上的服务驻留、退出登录、重启、独立模型请求和文件执行验证。发布云端安装包时保留第三方许可证，并核对运行环境及原生依赖的 Linux 兼容性。

### 6.3 验证交付

实施记录应包含被测提交、macOS 桌面环境、Linux 主机发行版与架构、Node 与 Host 版本、服务方式、命令、结果和未覆盖项。桌面验证使用独立 `HEMI_USER_DATA_DIR`，云端使用专用测试账号及目录，不接触个人凭据或真实项目数据。

变更同时涉及运行核心、IPC 与远端服务，应按实际影响选择测试，并直接验证生产实现。发布前必须覆盖真实 SSH 登录退出、云主机重启、控制通道断开、受理回执丢失及云端权限等待；只通过页面截图、mock 或健康检查不足以证明常驻链路完成。

本文件描述待开发能力。当前交付需求与独立视觉原型，未实现或验证真实云端 Bot；现有 Hemi 的测试结果不能作为本功能验收结果。

## 7 评审取舍

| 议题 | 本版处理 |
| --- | --- |
| 云服务器还是 Windows 云桌面 | 用户已明确 Linux 云服务器，经 SSH 接入；不引入 Windows 首版安装链路 |
| SDK 与常驻进程的关系 | 独立 Host 承载运行核心，SDK 不单独承担进程驻留 |
| 单 Bot 与多会话 | 一个入口和一个主机绑定，多条独立会话；不建立多 Bot 或多主机控制台 |
| Bot 是否另做精简聊天页 | 共用普通对话及非语音功能；按云端环境适配数据与工具，关闭语音和本机采集，附件属于通用输入范围 |
| 本机模型如何进入 Bot | 顶部小型“同步模型”入口，用户手动选择同步；每条会话从云端可用列表选模 |
| 运行目录 | 云端默认空间起步，每条会话可浏览并选择当前云服务器文件夹 |
| 是否迁移本机模型账号 | 首版使用云端可独立调用的接口，OAuth 迁移不在本版范围 |
| 是否必须内置浏览器和桌面 | 首版先完成文件与命令闭环，能力范围在页面和模型侧保持一致 |
| 是否增加卸载和任务调度 | 首版只提供必要维护操作；不增加删除云端数据、定时任务或外部渠道 |
| 重启后是否自动续跑 | 服务恢复与任务恢复分别处理，不承诺重放在途副作用 |

首版建议默认值及 Linux 安装支持矩阵应在实施前冻结；若调整输入方式、模型认证或云端工具范围，需同步修改引导、能力描述与验收标准。
