# Bot 组件版本

组件采用“应用主版本 + 组件修订号”：`package.json` 的应用版本为 `0.2.20`，根目录 `bot-component-version.json` 的 `revision` 为 `1`，生成的组件版本就是 `0.2.20.1`。只修复 Bot 时递增 `revision`，不推进桌面应用版本；发布新的应用主版本时可从修订号 `1` 开始。

桌面打包、开发环境组件更新和单独更新 Bot 均通过 `buildBotRuntime` 读取同一份修订号并与应用版本组合。修订号缺失、不是非负安全整数或应用版本无效时停止构建，不通过临时参数指定另一套版本。发布前合并需要上线的源码，再递增修订号并生成运行包；不要只改旧包的版本清单。

更新先按数字比较应用主版本的三段，再比较第四段组件修订号；相同版本继续比较源码指纹。旧三段版本仍可读取，按修订号 `0` 比较。清单的 `build` 标识实际打包内容，`archiveSha256` 核对上传归档。

此前单独部署曾将三段版本递增到 `0.2.25`，偏离了上述规则。迁移到 `0.2.20.1` 时按用户要求显式覆盖云端组件，普通自动更新仍保留防降级检查。后续统一使用四段组件版本，不继续独立递增应用版本的最后一段。较旧桌面尚不能解析四段版本，其维护检查会拒绝替换；新版桌面构建带入本次解析和比较逻辑后正常维护。
