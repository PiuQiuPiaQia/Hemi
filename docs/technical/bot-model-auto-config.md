# Bot 本机模型与路由自动配置

2026-10-24（Asia/Shanghai）。本机模型配置是 Bot 的自动配置来源；云端独立配置继续保留新增和编辑能力。电脑图标标记“本机”，服务器图标标记“云端”。不提供单独同步或导入入口。

## 配置与来源

初始化自动配置本机可用的 API Key 模型，并将主模型、explorer、oracle、fixer、designer、备用模型槽位一并配置到 Host。新增模型、模型／凭据变更、角色变更和删除均通过 profile store 变更通知自动更新，重连、启动与轮询负责补齐。初始化超过 50 个模型时按既有 RPC 上限分批验证；后续自动更新串行去重。

普通开发实例若与本机正式版的已保存绑定指向同一个 Bot，自动配置权归正式版。IPC 为开发服务注入正式版数据目录，仅比较绑定的实例身份；开发服务在后台配置、首次使用和手动同步边界阻止替换本机来源目录，并直接展示 Host 模型与角色配置。开发版绑定其他 Bot 时不受限制；显式 `HEMI_USER_DATA_DIR` 的隔离验证不读取正式版绑定。

Bot 设置中的模型页用于查看来源及维护云端配置。本机来源只读，“在本机修改”定位本机“模型与路由”；自动路由的齿轮也进入本机配置。云端供应商可新增或编辑名称、端点、协议、Key、型号、思考强度及图片能力。Key 不回传输入框，留空保留现存 Key，同组新增型号复用该凭据；整组验证成功后生效，稳定供应商／型号身份避免重复添加。

Host 将来源单独存入 `modelSources`，不改变既有模型版本摘要。旧版自动模型视为本机来源，旧版 `bot-<24 hex>` 手动供应商视为云端来源；来源跨重启保留。Host 拒绝跨来源覆盖，包括向本机供应商新增云端来源型号。`model.local-config` 只接受已验证的本机来源模型和角色引用，再移除本机已删除条目；云端独立配置不受本机同步影响。

OAuth、缺少 API Key 及本机回环地址显示不可用原因。模型验证失败保留原已验证版本；角色依赖未全部验证时保留原路由，界面不会把失败配置当成生效。验证期间再次修改本机配置，当前轮完成后立即重新核对。回执丢失先查原操作；失败限频重试，修正配置会恢复。配置目录损坏时保留云端原配置。

## 共用执行策略

Host 使用本机相同的 `freezeModelPolicy` 与 `resolveModelPlan`，运行会话复用 `sessionModelOptions` 和 Hemi routing extension。自动模式中主 agent 使用主模型，四个角色使用各自模型，未设置的角色跟随主模型，共用备用。具体模型模式中主／子使用准确选择的模型，禁止切备用。图片等任务要求与候选能力求交集，不按型号名称猜能力。

每条输入冻结完整公开策略与各候选的版本引用，密钥仅保留在 Host 的私有版本库。密钥轮换、模型删除和路由变更不改变在途或排队消息。旧版本只在最后一个排队／运行引用结束后回收。本机离线时 Bot 与手机继续使用最后验证成功的配置；重新连接后更新。

云端角色复用角色定义、派单工具与子 agent 管理器，工具限定为云端可用文件／命令能力。只读角色保留硬边界；角色授权进入所属根运行的现有权限卡，云端等待不使用桌面 30 秒超时。根运行停止会等待所属角色停止；后台报告经隐藏宿主事件交回主 agent 验收后再完成。角色定义随 Bot 运行包分发。移动端从 Host 元数据展示同一自动路由与来源图标。
