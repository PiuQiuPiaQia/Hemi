# 会话交付物展示

图片使用小尺寸缩略图与文件名，文件使用图标与文件名的一行卡片。类型、大小、说明放在悬停提示里，不另占正文行。图片卡宽度根据原图比例与可用空间调整，缩略图最高 120px，多图自动换行。完整文件通过既有右侧预览打开。

右键或 Shift+F10 显示少量与文件类型匹配的常用程序，底部提供“打开所在目录”。例如 Markdown 在本机显示 VS Code、文本编辑，图片显示预览类程序；不重复卡片的预览动作，也不穷举 Excel、浏览器等宽泛关联。候选来自 macOS NSWorkspace 的实际关联程序，按类型收敛到最多四个，标识实际默认项；没有匹配的常用程序时退到系统默认程序。

选择具体程序后，主进程再次解析文件身份与路径、重新查询应用是否仍可用，再用独立参数的 `/usr/bin/open -a` 打开；应用路径不由 renderer 提供。“打开所在目录”使用 `shell.showItemInFolder` 定位宿主解析出的文件，在访达中打开其目录并选中该文件。远端文件不交给本机程序打开。菜单复用现有 Menu 组件；加载列表后重新收敛位置，避免菜单越出视口。

会话右上角保留访达、终端、VS Code 三种常用目录入口。本机项目、默认空间和旧会话均显示；默认空间首次打开时按需创建其目录，旧会话的家目录由主进程解析，不指向默认空间。远端项目仍不在本机打开。

## 文件来源与恢复

- 正式交付按主机和真实路径识别，同回合只展示一次，后续回合更新仍保留入口并复用预览标签。
- 登记成功但时间线缺少入口时，从 registry 的生产归属恢复到对应回合；旧的独立 root 入口合并回该运行的助手行。
- 正文明确的 Markdown 文件链接、图片引用、完整行内代码路径可以成为预览候选，经宿主校验后读取，不自动登记为正式交付。
- 旧会话若只交代成果目录，只有“正文明确交付该目录、工具成功读取对应图片、图片已存在正式登记”同时满足时才恢复图片入口。普通读取的参考图不自动展示为成果。
- 新文件身份包含主机与完整路径的摘要，避免中文、特殊符号和长路径清洗后撞号；旧档案已有身份继续复用。
- 主进程先冲刷工具前的内容，再按实际输入锚点登记；远端查证保留原代次，成功回合收口前等待查证，避免入口漂到 root 行或迟到丢失。

图片仅在卡片进入视口附近时读取。读取结果绑定会话、文件和内容版本，切换、卸载或更新后的旧响应不覆盖当前状态。读取失败保留原因与重试。
