桌面 AI 助手

不止帮你想。陪你做到交付。

用文字或语音交代一件事，Hemi 在你的电脑上把它做完：查资料、改文件、跑命令，最后把结果交到你手里。

免费下载 在 GitHub 查看

macOS（Apple Silicon）· Windows（x64）· MIT 开源

它能帮你做的

  1. 用你已有的 AI

    登录产品支持的订阅账号，接入 New API 站点，或填写接口地址和 API Key 自定义接入。模型都进同一个列表。

  2. 合适的模型做合适的事

    主模型和侦察、顾问、执行、设计等角色可以分别配模型，按任务需要协作，兼顾能力和调用成本。

  3. 不止在这台电脑上工作

    通过 SSH 在远程主机上干活；也可以把任务交给部署在你自己服务器上的 Bot。

    服务器在线时，Bot 已受理的任务会在你关闭本机或断开后继续推进。普通 SSH 工作需要本机保持连接。

  4. 说过一次，下次照做

    把偏好写进记忆，之后的对话直接沿用。

    每台桌面、每个 Bot 各有一份记忆，不会自动跨主机同步。

  5. 常做的事存成工作流 Beta

    视频剪辑、文案发布、资料整理这类反复做的事，自己建成流程，需要时选中运行，运行前由你确认。

    流程需要自己创建，目前没有定时触发。
