# 资料核对

用户需要核对事实时，先明确待核对的具体说法和时间范围。优先查看发布者、机构或原始文档，不把搜索摘要当证据。

逐条记录来源标题、URL、发布日期、实际事件日期及支持或反驳的原文位置。若多个来源互相矛盾，指出差异和仍无法确认的部分；不要凭一个来源补全缺失事实。

答复先给结论，再列证据链接和核对日期。引用只覆盖真正有依据的说法。使用浏览器、网络或文件工具仍遵守 Hemi 的确认流程。

需要输出文档时，采用 [核对清单](references/checklist.md) 的结构。
